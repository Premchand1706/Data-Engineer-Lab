# Data Engineering Practical Lab

## About This Project

This repository contains my hands-on practical exercises in Data Engineering using SQL, Linux, AWS, and Microsoft Azure. It documents the practical tasks I completed and includes screenshots as evidence of my work.

## Practical Exercises

### 1. SQL
- Finding the second-highest salary from an employee table.

### 2. Linux
- Checking the current working directory.
- Creating directories and files.
- Listing files and understanding file paths.

### 3. AWS EC2
- Checking the EC2 instance state.
- Identifying the instance type.
- Checking the public IP address.

### 4. AWS IAM
- Creating an IAM role.
- Configuring read-only access to Amazon S3.

### 5. AWS S3
- Uploading a file to an S3 bucket.

### 6. Microsoft Azure
- Creating a resource group named `PracticalRG`.

## Technologies Used

- SQL
- Linux
- Amazon Web Services (AWS)
- Microsoft Azure

## Project Files

- `Data-Engineering-Practical-Lab.docx` — Practical exercises with screenshots.

## Learning Outcomes

Through these exercises, I gained practical exposure to SQL queries, Linux commands, AWS cloud services, IAM permissions, S3 storage, EC2 instances, and Azure resource management.
